計算の前提

日射比例かん水の基本は100〜120 mL/株/MJ、草勢を強めるときは140〜160、弱めるときは70〜90（マニュアル 表2-3）。ここに飽差の補正をかけ、株あたりの実数にしています。飽差が高い日は蒸散が進むため増やし、低い日は減らします。かん水回数は1日1〜14回の範囲で、日射量から割り振ります。

回帰分析

環境データ（CSV取込）と生育調査データを組にして、単回帰で関係を見ます。

重回帰：気温 × DIF

平均気温とDIF（昼夜温差）を同時に使い、Yを説明します。単回帰より実際の管理判断に近づきます。Yは上の欄と共通です。

読み方

環境の変化が生育に表れるまで7〜14日かかることが分かっています（マニュアル追補1）。まずは自動探索でどのラグが強く効いているかを見て、そこから茎径は気温・DIFとの関係を、節間長は湿度・飽差との関係を確認するのがおすすめです。r（相関係数）は−1〜1、絶対値が0.5を超えると関係ありとみなせます。n（組の数）が少ないと数値がぶれやすいので、5組未満のときは参考程度に。重回帰のR²は、気温とDIFの両方を使ったときにYのばらつきをどれだけ説明できるかを示し、単回帰のr²と見比べると、DIFを加える意味があるかどうかが分かります。

環境データ（CSV取込）と生育調査データが3組以上そろうと計算できます。

環境データを読み込む

記録計のCSVを、選択中のハウスに取り込みます。気温だけ、湿度だけといった1項目ずつの書き出しでかまいません。気温のCSVと湿度のCSVは別々に、1回ずつ取り込んでください。同じ時刻の値は項目ごとに上書きされるので、両方取り込むと自動で飽差が計算されます。複数ファイルの選択は、同じ項目を日付違いで分けて書き出した場合にまとめて読むためのものです。

集計のしかた

読み込んだ値はまず1時間ごとに平均し、そこから日別の平均・最高・最低・昼温（6〜18時）・夜温・DIF・平均湿度・平均飽差を出します。1分間隔でも10分間隔でもそのまま読めます。飽差は気温と相対湿度がそろった時刻だけで計算します。

書き出し

CSVは表計算ソフトで開けます。移行用JSONは、このアプリを別の端末やブラウザに丸ごと引っ越すためのものです。

環境データは3段階で書き出せます：時別CSV＝取り込んだ生データに近い1時間ごとの値、日計CSV＝そこから作った日別の平均・DIF・飽差など、週計CSV＝月曜始まりの1週間ごとにまとめた平均値です。この6種類のCSVはすべて、下の移行用JSONに含まれる元データ（ハウス・調査記録・液肥・環境時別）から作れるので、JSON1つを保管しておけば内容として失われるものはありません（日計・週計はJSON自体には計算済みの形では入っておらず、環境時別データから同じ計算式でいつでも作り直せます）。

サインインの準備

初回だけ、Googleに「このアプリ」を登録します。費用はかかりません。

1このHTMLを https:// か http://localhost で開ける場所に置きます。ファイルを直接ダブルクリックして開いた状態（file://）ではGoogleのサインインが使えません。手元で試すならフォルダで python -m http.server 8000 を実行し http://localhost:8000 で開きます。
2Google Cloud コンソールでプロジェクトを作り、APIとサービス＞ライブラリ から Google Sheets API、Google Drive API、Google Calendar API を有効にします。
3OAuth同意画面を「外部」で作成し、公開ステータスは「テスト」のまま、テストユーザーに自分のGoogleアカウントを追加します。
4認証情報＞OAuthクライアントID＞ウェブアプリケーション を作成し、承認済みJavaScript生成元に手順1のURL（例 http://localhost:8000）を登録します。
5発行されたクライアントIDを左の欄に貼り、サインインします。

求める権限は、このアプリが作った／指定したスプレッドシートの読み書き（drive.file・spreadsheets）と、カレンダーへの予定追加（calendar.events）だけです。ほかのファイルには触れません。

サインアウトの準備

データが消えないよう、サインアウトする前に確認してください。

1未送信の変更がないか確認します。記録を追加・編集した直後は、上の「この端末の内容を送る」を押して、最新の内容をスプレッドシートに反映させてください。
2心配な場合は、「ログイン」タブの書き出しから移行用JSON（全データ）やCSVをダウンロードし、念のため手元にも控えを残してください。
3複数端末で使っている場合、この端末の最新の内容を他の端末でも使いたいときは、その端末側で「シートから取り込む」を行ってください。この端末をサインアウトしても、スプレッドシート上のデータは消えません。
4サインアウトすると、この端末はスプレッドシートと同期できなくなります。ただしブラウザに保存されているこの端末自身のデータは消えず、再びサインインすればいつでも同期を再開できます。
5スプレッドシート自体の削除・共有解除は、このアプリからはできません。必要な場合はGoogleドライブ側で操作してください。

サインアウトは、この端末の認証を解除するだけの操作で、データそのものを削除するものではありません。ただし送り忘れた変更は、次にサインインしてスプレッドシートに送るまで反映されない点にご注意ください。
